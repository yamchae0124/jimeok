# 지먹 (jimeok) — 국토부 실거래가 지도 도구

국토교통부 아파트 매매 실거래가를 지도 위에 시각화하는 도구입니다.
지역을 선택하면 단지별 평당가와 인프라(학교·백화점·관공서·운동장), 교통(철도·고속도로),
행정구역 경계, LH 공급공고, 통근시간을 한 화면에서 토글하며 볼 수 있습니다.

## 배포

- 웹: <https://yamchae0124.github.io/jimeok/>

## 사용법

1. **랜딩(허브)** — `index.html`을 열면 수집된 지역 카드 그리드와 전체 집계(거래·임대·단지 수)가 표시됩니다.
2. **지역 선택** — 카드를 클릭하면 `map_leaflet.html?region=<법정동코드>`로 해당 지역 번들(`regions/<lawd>/map_data.js`)이 로드됩니다.
3. **지도** — Leaflet 기반, 서버 불필요. 실거래가·인프라·교통·행정·LH·통근 레이어를 토글하고,
   줌 3단(멀리/중간/가까이)에 맞춰 마커·라벨 밀도가 자동 조절됩니다.
4. **경쟁단지 모드** — 선택 모드에서 단지를 클릭해 경쟁단지로 지정(최대 9개)하거나 자동 추천(반경·연차·주력평형 스코어링)을 받습니다.
   9색 팔레트로 색을 구분하고, 통계 패널에서 타입별 평당가·거래량·최고점·역대 최고점을 비교합니다.
5. **내보내기(export)** — 통계 패널에서 PNG·보드·xlsx·csv·비교표·pptx·선택 저장 7종을 브라우저 안에서 생성합니다.

자세한 로컬 사용법은 [사용가이드.md](사용가이드.md)를 참고하세요.

## 로컬 파이프라인

**수집 → 빌드 → 뷰어** 3단계로 동작합니다.

1. **수집** — `collect.py`가 국토부 실거래가 API로 지역(법정동 코드) 거래를 수집해 SQLite(`data/`)에 저장합니다.
2. **빌드** — `geocode.py`·`build_map.py`·`infra.py`·`transit.py`가 수집 데이터를 지도용 JS 번들로 변환합니다.
   `python switch_region.py "<주소>" <법정동코드>` 한 줄이면 지역 전환 전 과정(수집→지오코딩→지도→인프라→교통)이 자동 실행됩니다.
   여러 지역 허브 조립은 `python build_hub.py`(외부 API 호출 없음 — SQLite→JSON 변환만).
3. **뷰어** — `map_leaflet.html`(정본 지도)을 브라우저에서 열면 됩니다. Leaflet 기반, 서버 불필요.

배포는 GitHub Actions(`.github/workflows/deploy.yml`)가 커밋된 정본과 지역 번들로 `site/`를 조립해
Pages에 올립니다. 빌드 단계가 없으므로 CI에서 외부 API를 호출하지 않습니다.

### 로컬 전용 파일 (공개 레포에 없음)

지역 설정과 API 키는 사업지·개인 정보를 담아 **로컬 전용 파일로 관리하며 공개 레포에서 제외**됩니다:

| 파일 | 역할 |
|---|---|
| `config.json` | 지역·반경 설정 단일 진실 |
| `_config.py` | config 로더 (기본값 포함) |
| `.env` | API 키 (국토부·카카오) |

로컬에서 실행하려면 `config.example.json`을 `config.json`으로 복사해 값을 채우고,
`.env`에 키(`DATA_GO_KR_KEY`·`KAKAO_REST_KEY` 등)를 입력하세요.

## 데이터 출처

- **국토교통부 아파트 매매 실거래가** (공공데이터포털 RTMSDataSvcAptTradeDev)
- 평당가는 전용면적 기준. 신고지연으로 최근 1~2개월은 비어 있을 수 있고, 해제(취소) 거래는 제외됩니다.
- 인프라 레이어는 카카오 로컬 API, 교통 레이어는 OSM 데이터를 사용합니다.
- 지역 번들의 데이터 기준 시점은 각 번들의 빌드 시각(`meta.generated_at`)입니다.

## 면책

- 이 도구는 시장조사 목적의 도구이며, 제공되는 수치는 국토교통부 실거래가 공개데이터에 기반합니다.
- 데이터는 기준일(`generated_at`) 이후 변경·추가될 수 있으며, 최신성을 보장하지 않습니다.
- 정보의 정확성·완전성을 보증하지 않고, 활용에 따른 어떠한 책임도 지지 않습니다.
