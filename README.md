# 지먹 (jimeok) — 국토부 실거래가 지도 도구

국토교통부 아파트 매매 실거래가를 지도 위에 시각화하는 도구입니다.
지역을 선택하면 단지별 평당가와 인프라(학교·백화점·관공서·운동장), 교통(철도·고속도로),
행정구역 경계, LH 공급공고, 통근시간을 한 화면에서 토글하며 볼 수 있습니다.

## 배포

- 웹: <https://yamchae0124.github.io/jimeok/> (예정 — 공개 배포 준비 중)

## 로컬 파이프라인

**수집 → 빌드 → 뷰어** 3단계로 동작합니다.

1. **수집** — `collect.py`가 국토부 실거래가 API로 지역(법정동 코드) 거래를 수집해 SQLite(`data/`)에 저장합니다.
2. **빌드** — `geocode.py`·`build_map.py`·`infra.py`·`transit.py`가 수집 데이터를 지도용 JS 번들로 변환합니다.
   `python switch_region.py "<주소>" <법정동코드>` 한 줄이면 지역 전환 전 과정(수집→지오코딩→지도→인프라→교통)이 자동 실행됩니다.
3. **뷰어** — `map_leaflet.html`(정본 지도)을 브라우저에서 열면 됩니다. Leaflet 기반, 서버 불필요.

자세한 사용법은 [사용가이드.md](사용가이드.md)를 참고하세요.

### 로컬 전용 파일 (공개 레포에 없음)

지역 설정과 API 키는 사업지·개인 정보를 담아 **로컬 전용 파일로 관리하며 공개 레포에서 제외**됩니다:

| 파일 | 역할 |
|---|---|
| `config.json` | 지역·반경 설정 단일 진실 |
| `_config.py` | config 로더 (기본값 포함) |
| `.env` | API 키 (국토부·카카오) |

로컬에서 실행하려면 `config.example.json`을 `config.json`으로 복사해 값을 채우고,
`.env`에 키(`DATA_GO_KR_KEY`·`KAKAO_REST_KEY` 등)를 입력하세요.

## 데이터 출처

- **국토교통부 아파트 매매 실거래가** (공공데이터포털 RTMSDataSvcAptTradeDev)
